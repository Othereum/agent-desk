# 서브에이전트에 일을 맡길 때

여러 태스크를 병렬 에이전트(서브에이전트)에 맡길 때 따른다. CLI와 기록 규칙은 `SKILL.md`를 따른다.

- 서브에이전트는 메인 세션과 같은 세션 ID를 쓴다. 그래서 **서브에이전트는 이 세션의 포커스를 바꾸지 않는다**(`focus` 금지). 메인 에이전트는 서브에이전트에 넘기는 지시에 태스크 ID와 이 파일의 규칙을 넣는다.
- 포커스 태스크 범위 안의 일을 맡기면, 서브에이전트는 그 태스크 ID로 기록한다.
- 다른 태스크의 일을 맡기면, 서브에이전트는 지시받은 태스크 ID를 명시해 기록한다. 포커스에 기대지 않는다.
- worktree에서 만든 브랜치를 태스크에 이어 둘 일이면 `link <id>`로 연결한다.
- 서브에이전트는 세션 시작 주입을 받지 않으므로 태스크와 상위 태스크의 state.md·decisions.md를 직접 읽는다.
- 각 에이전트는 자기 태스크 기록만 고친다. 상위 태스크 반영(현재 상태 한 줄, 흐름 전체의 결정)은 메인 에이전트가 결과를 모아 한다. 동시에 고치면 서로 덮어쓴다.
