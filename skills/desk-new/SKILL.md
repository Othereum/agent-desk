# agent-desk 작업 생성

CLI 경로와 기록 규칙은 `agent-desk:desk` 스킬을 따른다.

1. `python <desk.py> where`로 현재 상태를 확인한다.
   - `project`가 없으면 `agent-desk:desk-init` 절차를 먼저 진행한다.
   - `task`가 이미 있으면 새로 만들지 않고 그 작업을 알린다.
2. 제목을 정한다. 사용자가 주지 않았으면 대화 맥락으로 한 줄 제목을 제안한다.
3. 작업을 만든다.
   - 현재 브랜치에 연결: `python <desk.py> new --title "제목"`
   - 브랜치 없는 작업(조사 등): `python <desk.py> new --title "제목" --no-branch --slug <영문-슬러그>`
   - 공용 브랜치(main 등)에서는 브랜치 연결이 거부된다. 새 브랜치를 만들지, 브랜치 없는 작업으로 만들지 사용자에게 묻는다.
   - **상위 작업**: 이 작업이 진행 중인 큰 흐름의 일부라면 `--parent <id>`를 붙인다. `list`로 진행 중인 작업을 확인하고, 해당할 만한 작업이 있으면 사용자에게 한 줄로 확인한다. 큰 흐름이 이제 시작되는 경우라면 상위 작업을 먼저 브랜치 없이 만들지 제안한다.
   - **연관 작업**: 다른 작업의 후속이거나 그 작업을 참고해야 하면 `--related <id>`를 붙인다.
4. 생성된 `state.md`의 섹션을 대화에서 알고 있는 내용으로 채운다(목표, 현재 상태, 다음 할 일, 미해결 질문, 핵심 파일). 관련 링크(이슈, PR, 외부 문서)가 있으면 frontmatter `links`에 넣는다.
5. **관련 지식**: 제목과 대화의 핵심어로 `python <desk.py> kn search <검색어...>`를 실행하고, 핵심 파일이 있으면 `kn search --path <파일>`도 실행한다. 관련 있는 항목만 "관련 지식" 섹션에 `- K0012 제목` 형식으로 적는다. 없으면 섹션을 비워 둔다.
6. 이 세션에서 이미 확정한 결정이 있으면 decisions.md에 D1부터 기록한다.
7. **설계 문서**: `agent-desk:desk` 스킬의 "Claude Docs 설계 문서" 기준에 해당하면 만들기를 한 줄로 제안한다. 사용자가 동의하면 docs 스킬 절차로 문서를 만들고 URL을 `state.md`의 `design_doc`에 기록한다. 해당하지 않으면 묻지 않는다.
8. 사용자에게 작업 ID와 폴더 경로(설계 문서를 만들었으면 그 링크도)를 한 줄로 알린다.
